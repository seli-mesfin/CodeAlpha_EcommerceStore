# CodeAlpha_EcommerceStore

This is a full-stack MERN (MongoDB, Express.js, React, Node.js) E-commerce application developed as part of my internship at CodeAlpha.

## 🚀 Features
* **User Interface**: Responsive frontend built with React.
* **API**: RESTful backend services built with Node.js and Express.
* **Database**: Data managed with MongoDB and Mongoose.

## 🛠️ Prerequisites
* [Node.js](https://nodejs.org/) (v16 or higher)
* [MongoDB](https://www.mongodb.com/) (or a MongoDB Atlas connection string)

## 📦 Installation & Setup

1. **Clone the repository**: `git clone https://github.com/seli-mesfin/CodeAlpha_EcommerceStore.git` and `cd CodeAlpha_EcommerceStore`.
2. **Setup Backend**: Navigate to the `backend` folder, run `npm install`, and then run `npm start`. Ensure you have a `.env` file with your `MONGO_URI`.
3. **Setup Frontend**: In a new terminal window, navigate to the `frontend` folder, run `npm install`, and then run `npm start`.
